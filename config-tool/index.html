Hexablow Config

Open the config files

This page is not connected to the project. Pick one way:

  1. Recommended: run node config-tool/serve.mjs in the project and open http://localhost:5190/. Save then writes straight into src/*.json.
  2. Open the project folder here (Chrome / Edge). Save writes into it directly.
  3. Or choose the JSON files by hand (src/tuning.json, economy.json…). Save downloads each file; copy it back over the original.

This browser can't open folders; use Open files.

Needs npm run dev running. Vite reloads the game by itself when a JSON file changes.
